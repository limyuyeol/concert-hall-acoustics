# 홀의 소리 · 콘서트홀 음향실험실

건축음향 개념을 시각화하는 교육용 웹 시뮬레이션입니다.

실행: https://limyuyeol.github.io/concert-hall-acoustics/

- 432개 객석을 갖춘 3D 테라스·발코니 홀
- 반사판·재질·관객 점유율 비교와 합성 청취
- 선택 객석의 직접음·반사음 확대 화면
- 자동 학습 시연과 실험 카드 PNG 저장

정적 HTML/CSS/JavaScript로 동작합니다. 별도 설치 없이 브라우저에서 실행합니다.
음원 업로드는 브라우저 안에서 처리합니다. 설계는 브라우저 저장소에 보관됩니다.

실제 공연장의 실측 복제나 전문 음향 예측 도구가 아닙니다. 재질 값과 후기 잔향은 교육용 근사이며 회절·간섭을 해석하지 않습니다. 수업자료 원문은 저장소에 포함하지 않았습니다.
